
# 검색광고 키워드 추출기 v3

개발자가 아닌 사용자가 웹에서 간단하게 사용하는 버전입니다.

## 사용법

1. 사이트 주소 입력
2. 추출 목적 선택
3. 업종 선택 또는 자동 감지
4. 추천 조합어 확인
5. 자동 추출 시작
6. 결과 확인
7. 엑셀 다운로드

## 추출 목적은 이렇게 고르면 됩니다

- 네이버 파워링크 세팅:
  실제 파워링크에 넣을 구매/상담 의도 키워드가 필요할 때

- 검색광고 키워드 확장:
  기존 키워드 외에 연관 키워드와 롱테일을 넓게 찾고 싶을 때

- 쇼핑검색광고 세팅:
  상품 구매/가격/배송 중심 키워드가 필요할 때

- SEO/콘텐츠 키워드:
  후기, 방법, 비교 등 정보성 키워드까지 폭넓게 찾고 싶을 때

- 경쟁사/시장 키워드 조사:
  경쟁사 사이트의 상품/서비스 구조를 바탕으로 키워드 풀을 만들 때

## 추가 조합어는 직접 생각하지 않아도 됩니다

목적 + 업종에 따라 추천 조합어가 자동으로 채워집니다.
필요한 경우만 수정하면 됩니다.

예:
식물/조경 + 파워링크
→ 구매, 판매, 가격, 배송, 택배, 묘목, 모종, 정원수, 조경수, 농장 등 자동 추천
